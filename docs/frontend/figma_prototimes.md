# User Interface Wireframes

The wireframe prototypes related to the new functionalities can be accessed through the following Figma project:

**Figma Link:**  
https://www.figma.com/design/Etqp1DdKABTyp0GonHDbPM/Mitelovers-Prototypes?node-id=9009-6678&t=9sdFQzJToIdvNcd8-0

These prototypes were created to support the analysis and design of the user interface, providing a visual representation of the interaction between users and the system.

The wireframes are intended to facilitate requirement validation and discussion before implementation.

## Notes

- The wireframes represent the proposed user interface and interaction flow.
- They are intended for analysis and validation purposes.
- The final implementation may differ slightly due to technical constraints or usability improvements identified during development.

## Covered Functionalities

- As a User, I want to use a Web UI to register a new publication in the system and add the publication to my library.
- As a User, I want to use a Web UI to create a private list of my publications, give it a name, set a genre and, eventually, share it.
- As a User, I want to get the list (title, author, type and ISBN/SSN) of publications in my library.
- As a User, I want to use a Web UI to add one of my publications to a list of mine.
- As a User, I want to use a Web UI to publicly share a list of mine.
- As a User, I want to use a Web UI to put for sale a publication in my library in a direct sale.
- As a Buyer, I want to use a Web UI to get the list of items on direct sale of a given genre.
